## 4. Protocol by reference + lane rulings

HANDOFF_PROMPT.md remains operative (§§4-6, 8-10). Milestone-specific rulings:

- **Ruling A — the guard extends to every new prose surface.** README.md introduces numeric claims; the G0-G4 contract applies to it the way it applies to WRITEUP.md. The locator builder gains README locators; G2's surface list grows; G3's token scan covers README.md. Numbers without a locator or a reasoned exemption cannot appear. This is non-negotiable: the repo audits published numbers and therefore cannot publish unguarded ones.
- **Ruling B — release notes are derived, not transcribed.** The release body is generated by the same locator builder into a file, then published via `gh release create v1.0.0 --target main --notes-file ...`. The tag points at existing commits — the SHA-reference contract (writeup/ledger cite `c842e85`, `be55c16`, `b009ecc`, ...) is untouched by tagging.
- **Ruling C — no vanity metrics.** No star counts, no "as seen on", no download numbers, nothing that changes after commit. Every number in the README must be as frozen as the artifacts.
- **Ruling D — every push is now publicly visible.** Commit messages are part of the front door; write them accordingly.
- **Ruling E — English only in v1.** The writeup and the target audiences (HN/Zhihu technical readers) are served by one precise language; a translation lane can come later.
- **Ruling F — exemplar research is bounded and recorded.** Study 4-6 concrete repositories (URLs + what was borrowed/declined go into the ledger), not a general essay. Candidate seeds to verify and extend via web search: the upstream [deepseek-ai/DeepInfer](https://github.com/deepseek-ai/DeepInfer) README (the audited artifact's own front door), one high-star inference repo (vllm-project/vllm or sgl-project/sglang), one high-star eval/research repo (EleutherAI/lm-evaluation-harness or similar), one minimal-README exemplar (karpathy/nanoGPT), one reproducible-research exemplar found by search. Borrow structure and discipline (first-screen clarity, quickstart placement, caveats sections); decline per-repo idiosyncrasies that fight the house rules (unguarded numbers, vanity metrics).
- **Ruling G — no history rewrites, no force-push, ever** (main is published; §10).
